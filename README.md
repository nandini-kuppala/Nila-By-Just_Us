# Nila — By Just Us

An offline-first infant care companion.

This repository starts where the work started: a speech-processing project that
classified infant cries by cause. Everything after it is built on what that
project taught us — including where it was wrong.

## Layout

```
baby-cry-classifier/   The original coursework pipeline: feature extraction,
                       RandomForest cause classifier, LIME explainability and
                       a Streamlit interface.
```
